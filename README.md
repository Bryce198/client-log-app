# Client Log App

This is an internal application for employees to manage client records and for logging client interactions.

## Project Status

### 🚧In Development

The application is currently being built. The initial project structure and database design are being developed before implementing the API and the frontend.

## ⚡️Tech Stack

- 🐍Python
- 💨uv
- ⚡️FastAPI
- 🐘PostgresSQL
- 👉🏾React (planned)

## Planned Features

- Client record management
- Employee/user management
- Client interaction logging
- Interation types and history
- Authentication and authorization
- PostgreSQL database
- Web-based frontend
- Internal deployment

## Development

This project uses uv for Python project and dependency management. Create the virtual environment and install dependencies with the command: **uv sync**

Run the application as development features are implemented.

## Security

This repository contains application source code and configuration templates only.

Client information, employee credentials, API keys, database passwords, and other sensitive data must not be committed to the repository.
